Cloud Storage Sync

To sync your backups to cloud storage:

  1. Create a backup using the button above
  2. Locate the backup file in the backups/ directory
  3. Add the backups/ directory to your cloud storage sync folder (Dropbox, iCloud, Google Drive, etc.)
  4. Your backups will automatically sync to the cloud

Privacy Note: All data stays on your local machine. Cloud sync is optional and controlled by you.
